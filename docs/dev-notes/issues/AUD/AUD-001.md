## Description

Fourth-down offsetting penalties incorrectly announce turnover on downs despite replaying the down and retaining possession. Accepted replay-down penalties can produce the same false banner.

## Resolution / verification

Fix committed together with this tracker entry; see the issue history and commit links. Added engine-owned `PlayOutcome.turnover_on_downs`; actual-result displays and both CLI loops now consume it. Added 76 synthetic/public-fixture cases, including genuine failures, conversions, fumbles, special plays, and new/resumed games. Initial baseline: 29 expected failures, 33 passing controls. Current core: 4,381 passed, 8 existing skips; clean snapshot: 4,364 passed, 25 existing private-data skips. Full browser validation passed on an isolated rerun, including both full games and offline help; initial failure remains disclosed under VAL-001. No release contains this fix yet.
