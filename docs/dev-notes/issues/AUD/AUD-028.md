## Description

The owner observes clustered BLACK regions on generated passing charts and
requests more interspersed outcomes while preserving exact physical gameplay.
Changing generation seeds is not a distribution-preserving placement method:
finite quantile assignment can change weighted gains. Unrestricted row shuffling
also changes probability because printed rows have unequal dice weight.

## Resolution / verification

The [placement design](../../primary-chart-dispersion-proposal.md) precedes the
implementation and declares exact whole-token invariants, independent/coupled
roll scope, measurable objectives and feasibility limits. Fourteen new cases
fail before production; fourteen existing finite-allocation controls pass.
The local deterministic search swaps only equal-weight rows within each of the
nine primary columns. A separate checker preserves per-weight whole-token
inventories, including OOB markers, and fixes every nonprimary dependency.
Six negative controls reject probability, flag, rare-event, supplemental, row
and column corruption. High incidence/singleton groups can leave unavoidable
clusters; a local optimum is not a globally optimal visual arrangement.

Seventy-seven focused placement/allocation/generator tests pass. Two root-command
manifest tests fail before adding per-team placement receipts. Public core
distribution checks and all-team candidate generation are subsequent evidence.
Keep open pending exact all-team validation, frozen campaigns and owner review;
no private pattern is copied and no public candidate is promoted.
