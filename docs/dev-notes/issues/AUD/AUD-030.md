## Description

The shared engine-report validator independently reconstructs five source-fit
rates but does not check aggregate points per team-game, plays per team-game,
fumble-loss rate per play or field-goal rate. Altering any of those displayed
league/team values leaves accounting validation green. Paired comparison could
therefore report corrupted score/pace/special diagnostics despite valid raw counts.
This is a synthetic evidence-validation defect, not observed game-score corruption.

## Resolution / verification

Recompute every derived rate using the existing authoritative totals model,
preserving the five fixed source metrics/tolerances and all raw receipts. Reject
inconsistent, nonfinite, boolean or missing derived values. Revalidate current
campaigns and actual game/season integration before any acceptance claim; prior
runtime receipts cannot certify the changed measurement validator.
