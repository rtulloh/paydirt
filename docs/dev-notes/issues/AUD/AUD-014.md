## Description

Penalty-choice preview was reported to show penalty yardage instead of the retained play when the defense chart produced the foul. Defense charts never contain penalties (see RULE-003 re-scope), so the reported trigger cannot occur.

## Resolution / verification

When RULE-003 is picked up, verify the CLI preview (`handle_penalty_decision`) and the backend `_calculate_post_play_state` for the offense-chart reroll case: the accept-play preview must describe the rerolled result (numeric yards, breakaway/QT secondary roll, interception, incomplete, touchdown), not `play_result.yards`. Replace the UI-side `_calculate_post_play_state` recomputation with an engine-owned retained-play preview if any discrepancy is found.
