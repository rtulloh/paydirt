## Description

The real-browser chart test completes the chart rendering, team switching,
mobile scrolling and unchanged-game checks, then fails because Escape leaves
the CHARTS trigger inactive. The parent attempts to focus that button while
the native dialog is still modal; outside controls are inert at that point.
The previous jsdom dialog stub did not model this browser behavior.

## Resolution / verification

Close the native dialog before invoking the parent's unmount/focus callback.
Both Escape and the Close button use the same close procedure. Add regressions
that model modal inertness and require focus restoration for both exit paths.
Keep the real-browser focus assertion and also check the Close button there.
The fix is local and uncommitted. The user's focused browser rerun confirms
both exit paths restore focus; keep the ticket open until the fix is committed.
