## Description

The exact mechanics helper supplies numeric zero for absent B/QT cells.
The authoritative resolver uses the same uniform random fallback for both
missing and blank secondary rows: 15 through 40 yards for B, minus five through
ten for QT. A legacy missing-row limitation can therefore be understated as a
certain zero-yard gain with no fallback mass. This is an audit defect found
with synthetic cells; no private-corpus incidence is asserted.

## Resolution / verification

Use the actual empty secondary default and retain exact fallback mass, while
preserving primary/special default handling. Keep unresolved historical support
explicit. Verify the core fallback boundary, exact distribution and conservation
using synthetic controls, then repeat the complete private decoder/weighted
integration only at the stable checkpoint. Keep open pending that evidence.
