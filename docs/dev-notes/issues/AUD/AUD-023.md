## Description

The supplied local game log starts with both matchup names duplicated. The
CSV fallback assigns the directory name to both `PeripheralData.team_name`
and `team_nickname`; `TeamChart.full_name` then concatenates both without
checking whether they are the same. This is presentation/metadata debt,
not evidence of incorrect team charts or game rules.

Synthetic read-only probe: constructing a 2026 team whose name and nickname
are both `Sample` yields `2026 Sample Sample`. No historical chart cells
or narrative excerpts are needed to reproduce this.

## Resolution / verification

Decide whether fallback metadata should distinguish the display name from
the nickname, or whether the core full-name property should avoid identical
components. Keep the canonical team identity in the core; do not repair it
by rewriting names in individual UIs. Test equal and distinct components,
missing metadata, and public-team names before changing behavior. See the
[sanitized audit](../../game-audit-2026-10-28.md). No fix authorized.
