internal aliases, changed loaded policy constants, outside module origins and
missing runtime receipts. Freshly compiled definitions are compared with loaded
code throughout the audit's relative-import closure. Parent and workers check at
entry/exit; multiprocessing uses fresh spawned workers. Reports retain matching
worker identities, and validation requires the current loaded identity.

made/missed field goals and a zero-yard sack join the existing controls. An
erased-field-goal observer fails this conformance check. The focused suite passed

This consistency guard detects ordinary stale imports/replacement inside a
trusted process. It is not hostile-process attestation or the full charter's
frozen-snapshot/regression certificate. Root generation-script provenance and
complete readiness remain separate requirements. Keep open pending fresh final
campaigns and independent review.
