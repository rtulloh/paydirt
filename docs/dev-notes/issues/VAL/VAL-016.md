## Description

The frontend's relative guide-image requests return HTTP 500 while the normal
Uvicorn server listens on 127.0.0.1:8000. Node resolves the proxy target
`localhost` to `::1`, and Vite reports `ECONNREFUSED ::1:8000`. The same image
returns HTTP 200 directly from the backend. The isolated browser backend binds
`localhost`, which previously concealed the ordinary development-server case.

## Resolution / verification

Point Vite's `/api` proxy at `127.0.0.1:8000`, matching Uvicorn's default listener.
The existing real-browser offline guide test fails before this change because
its images cannot load; all eight chart browser tests pass in that invocation.
After the proxy correction, the unmodified guide test passes, all seven images
load, and a direct request through Vite returns HTTP 200. No assertion or skip
was changed. The backend and its existing games remain running.

The fix is local and uncommitted; keep this ticket open until committed.
