## Description

Release run 42415113069 passed its exact-commit CI gate, both chart checks and
all four platform builds, then failed publication with HTTP 403, Resource not
accessible by integration. The job logs show contents: write; a missing YAML
permission has not been established as the cause.

The maintainer authenticated through gh successfully published the existing
v1.10.1 tag and the same five artifacts. Public downloads were re-downloaded
and matched build artifact sizes and SHA-256 digests. This fallback completed
the release but did not repair automated publication.

## Resolution / verification

Determine the repository, token or GitHub integration restriction responsible
for the denied API operation. Apply the narrowest supported permission or
publication adjustment; never commit credentials. Preserve exact tested-commit
gating, immutable tags and artifact identities. Validate the next authorized
publication end to end; unit tests or successful artifact builds alone cannot
close this issue. Do not rebuild or replace existing release files merely to test.
