## Description

Found in the 2026-11-13 review of cedf6117..HEAD. `scripts/run_full_regression.py` builds the `clean_core` step from `git archive HEAD` in `_clean_core_checkout`. AGENTS.md requires verifying unit tests in a clean, tracked-files-only checkout so ignored local data cannot mask CI failures. When the script is run before committing, or with further edits staged after the last commit, the exported tree is the previous commit: the step can report a passing core run for code that is not the code under review, and it gives no indication that tracked changes were excluded.

## Resolution / verification

- `scripts/run_full_regression.py` now exports the candidate work tree instead of
  `git archive HEAD` (`export_candidate_tree`, `clean_core_checkout`). Tracked
  files are copied from disk, so staged and unstaged edits and tracked deletions
  are tested as they stand; new untracked-but-not-ignored files (for example a
  just-added test) are included, and ignored local data is still excluded.
  Submodule entries are skipped. Outside a Git work tree, or when `root` is not
  the work-tree top level, it raises instead of reporting a pass.
- The step prints the uncommitted tracked files it exported, and says `at HEAD`
  when the work tree is clean, so a receipt cannot hide which code was tested.
- Regressions in `tests/test_run_full_regression_script.py` build a scratch Git
  repository and prove: an uncommitted tracked edit reaches the export; a staged
  edit is included; a tracked deletion is omitted; new non-ignored files are
  included while ignored files are excluded; a non-Git directory is refused; and
  `clean_core_checkout` returns red for the old code and green only after the
  candidate fix. Baseline evidence: five of the new cases fail against the
  unchanged `HEAD` script (HEAD export absent, missing files, no refusal, and the
  clean run returning 0 for uncommitted work).
- Documented in the script docstring, `AGENTS.md` (one-command runner and
  clean-checkout requirements) and `docs/development.md`.
- Verified on the real candidate: `python3 scripts/run_full_regression.py
  --internal-clean-core` printed `clean checkout: exporting the candidate work
  tree with uncommitted tracked changes: M scripts/run_full_regression.py`,
  `M tests/test_run_full_regression_script.py`, and passed 11,401 tests in
  1,237 s. Focused suite: `tests/test_run_full_regression_script.py`, 23 passed.
