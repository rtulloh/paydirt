## Description

`paydirt-web/backend/tests/test_penalty_decision.py` defines its own
`_calculate_post_play_state` and tests that local copy; the similarly named
backend helper has no production callers. Those tests do not validate the
engine's actual pending-penalty projections. In the frontend, `KickoffPlay`
is imported by tests but not by the running application, and its touchdown
test is skipped (and does not click the kickoff button). `useGameLogic.ts` and
`utils/saveGame.js` likewise have no source callers and duplicate live flow or
save logic. These copies make test counts overstate coverage of active paths and
can drift from the actual implementation.

## Resolution / verification

Confirm which paths are supported, remove or consolidate obsolete copies and
their misleading tests, and cover actual engine/API penalty projections and the
running kickoff return touchdown flow with synthetic or public fixtures. Check
for other dynamic consumers before removing exports; preserve useful edge cases
and add no skips. Run focused backend and frontend tests and browser regression.
