## Description

Hand-rolled argv parsing in `paydirt/__main__.py`: help advertises `-l, --load` (`:262`, `:270`) but the dispatcher accepts only `--load`/`load` (`:327`), so `python -m paydirt -l x.json` falls into the interactive menu. The help note says the human commands the first team listed (`:286`) but ordering detection matches only the long `--away`/`--home` flags (`:477-478`), so `-p -A X -H Y` always makes the human home. `--play -d` is validated (`:420`) while `--load -d bogus --week abc` is accepted and passed through as difficulty "bogus" and week 0 (`:341-349`). Reproduced by invoking `main()` with stubbed entry points.

## Resolution / verification

- Accept `-l`; honor short-flag ordering or correct the help text; validate `-d`/`--week` on the load path identically to play. Tests over the dispatcher with stubbed entry points.
