## Description

`paydirt-web/AGENTS.md` instructs developers to run `npm run lint`, but
`paydirt-web/frontend/package.json` defines no `lint` script or ESLint setup.
Running the documented command fails with `Missing script: lint`. Python Ruff
does not cover frontend JavaScript and TypeScript.

## Resolution / verification

Choose and document a maintainable frontend lint workflow, or correct the
guidance if no frontend lint is intended. Ensure the documented command runs
and add it to appropriate automation if it is a required quality gate.
