## Description

The core suite reports eight skips on this checkout for missing 1972 charts,
rosters and season rules. Existing tests in `test_commentary.py`,
`test_interactive_game.py`, `test_season_rules.py` and `test_team_charts.py`
depend on historical local files; other cases use 1983 when present. This
contradicts the unit-fixture policy and means behavior differs between clean
checkouts and private-data workspaces. Meaningful checks such as season
filtering, old-rule conversion, roster loading and chart parsing can be
expressed using synthetic fixtures or the public sample data.

## Resolution / verification

Move genuinely historical integration checks to an explicit local-only runner
and replace useful unit scenarios with self-contained public or synthetic
fixtures. Run the core suite with only tracked files and no historical data;
ensure behavioral assertions remain meaningful and no new skip guards are
added. Review all historical data references, not just the eight current skips.
