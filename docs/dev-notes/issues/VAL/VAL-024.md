## Description

The current AGENTS.md pre-push checklist requires the strict generated-chart
source component audit for both committed 1983 and 2024 seasons. The exact audit
options fail before games because no current `.ai-audits/chart-sources/SEASON/`
preparation is available. Attempting preparation from the preserved source bundles
whose 84/96 chart CSV hashes match the committed charts also fails:
`Candidate manifest, source season or declared profile differs from contract`.

Committed seasons now carry public manifests with an original-manifest hash and
no complete private input inventory; the strict source preparation still expects
the original manifest and full input hashes. Current public contracts additionally
disclose existing accuracy exceptions. The strict engine fit validator does not
treat those disclosures as passes. Public source-free CI chart checks and local
strict source/fit qualification are distinct; neither may be silently substituted
for the other while AGENTS.md requires every command to pass before every push.

This blocks even a reviewed harness-only integration push, hence the updated
native Windows diagnostic workflow cannot be dispatched upstream yet. It is
separate from staged 1977 fit failure DATA-046. No token/access grant is missing.

## Resolution / verification

Agree on and implement an explicit validation contract for current public chart
manifests, independently binding actual published chart bytes to retained source
and reproduction evidence where required. Preserve private source facts locally,
public privacy boundaries, exact input/chart hashes and truthful existing fit
failures. Do not rewrite source totals, delete known failures, change tolerances,
claim a public decoder check proves source accuracy, or silently waive the current
pre-push checklist. Any source-manifest compatibility behavior requires synthetic
failing controls before code changes and actual review.

The owner explicitly authorized a distinct unchanged-release regression policy on
2026-11-09. The implemented route pins the actual v1.10.3 commit and public inputs,
rejects changed charts/provenance/contracts and gameplay, and preserves exceptions
without claiming fresh source/fit qualification. New/regenerated charts still
require strict gates. See [released-chart regression](../../../released-chart-regression.md).
Integration evidence and actual review are required before resolving this ticket;
native Windows acceptance remains separately tracked by VAL-023.
