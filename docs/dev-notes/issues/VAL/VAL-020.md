## Description

The successful 12c15dd upstream core job took 54m58s, with 10,801 tests passing.
The v1.10.0 Python 3.10 coverage run took about 69 seconds for 6,759 passing
tests and 25 skips. Chart jobs now take about 20 seconds each and are not the
bottleneck. Expanded tests repeatedly generate real charts and run simulations.

An earlier completed log spent about 57 minutes between 19% and 30% progress,
and another 12 minutes around 71% to 73%. Exact per-test durations were not
recorded, so these intervals do not identify individual tests conclusively.
Source review found repeated generation in function-scoped chart visual fixtures.

## Resolution / verification

Record slow-test durations and profile representative expensive cases. Share
immutable generated fixtures where independence permits, and distinguish genuine
end-to-end generation checks from repeated assertions on the same artifacts.
Preserve cases, coverage, assertions and public-only fixture requirements; do not
hide slow regressions with skips. Compare equivalent cold hosted runs before and
after changes and publish the remaining cost. Existing full-suite deduplication,
compatibility subsets and exact-commit release CI reuse must remain covered.
