## Description

Season and team lookup routes derive local data paths from request-supplied
identifiers. Review found that the current boundary validation may not keep
every lookup within configured season roots, including replay-loading paths.
This could expose local file content to API callers. Exact request inputs,
endpoint details and target paths are omitted from this upstream issue record
until the boundary fix is deployed.

## Resolution / verification

Validate identifiers against allowed entries and confine resolved paths to
configured roots, including symlinks and replay loading. Use temporary
synthetic directories to cover invalid identifiers and valid configured
seasons. Return a controlled client error without disclosing outside data.
