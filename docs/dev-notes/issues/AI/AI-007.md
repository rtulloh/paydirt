## Description

Base incomplete-pass durations appear long in some logs.

## Resolution / verification

User approved five-second incompletions throughout regulation and overtime,
adopting the incomplete-pass entry of the supplied 2008 rules' optional
Alternate Timing Method (printed pages 22–23; PDF pages 26–27). That entry
has five seconds of action time and zero dead time. This is a deliberately
scoped adoption, not a claim that the missing standard Timing Chart has
been reproduced or that the full alternate timing system is now enabled.

The core applies five seconds in direct play, the penalty-procedure path,
a retained incomplete result after declining a foul, and incomplete Hail
Mary attempts. In/out-of-bounds designations and no-huddle cannot change
that charge. `7T` costs five seconds but no timeout; planned spikes and
defensive timeout requests are also unnecessary. Offsetting fouls still
use ten seconds; accepted-penalty enforcement timing is unchanged.

The subsecond rounding guard now preserves a genuine one-second remainder:
a five-second incompletion from 0:06 leaves 0:01 rather than ending the
period. This is not an extension of time beyond the charged duration.

Initial test-first baseline: 62 expected timing failures and 12 passing
controls before production edits. The final dedicated public/synthetic
suite has 92 cases, including period boundaries, warnings, overtime,
fourth downs and individual/combined timeout and spike requests.

Existing expectation changes are explicit:
- SPIKE-002 CLI incompletions now expect five seconds instead of the old
  35-second midpoint; timeout/down/possession assertions remain intact.
- Penalty-clock clean/declined incompletions expect five seconds without
  a uniform timing draw. Accepted penalties retain their original checks.
- Declined defensive-foul expiry scenarios now start at five seconds,
  rather than 39, so the retained incompletion actually expires the period;
  the no-untimed-down/period-end assertions remain intact.
- One seeded public game now reaches sudden-death overtime. Its former
  universal zero-clock final expectation was invalid: an overtime-winning
  touchdown may end the game with time left. The test now requires that
  winning touchdown explicitly and retains all final-state/score checks.

Issue-specific play-test confirmation: four complete public CLI games
(seeds 19830601, 19830914, 8306, 8307; Ironclads at Thunderhawks) observed
55 finalized incompletions, including seven inside the last two minutes
of Q2/Q4 and ten with no-huddle. Instrumentation asserts every such engine
clock request is exactly five seconds and never OOB timing. All four games
finished with reconciled period scores and no pending untimed down.
Standings persistence was disabled. Close on this direct full-game evidence,
not unit tests alone. The separate halftime ambiguity remains TRACE-009.
