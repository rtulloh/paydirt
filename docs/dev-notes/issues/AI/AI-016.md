## Description

CPU never acts on kickoff-chart penalties: option labels use the opposite OFF/DEF convention, so the eligibility filter is always empty. The kick-chart `PenaltyChoice` also sets `offended_team` inverted relative to every consumer (CLI, auto game, web treat the receiving team as "offense" at a kickoff, which RULE-013 now documents and tests for the return phase), so the wrong side is asked.

## Resolution / verification

Flip the kick-phase `offended_team`/option types to the receiving-team-as-offense convention, drop the synthetic "DECLINE" option (AUD-020 pattern), and evaluate the accept/decline pair directly; update `test_def_penalty_on_kickoff_chart_offers_choice` (its "defense = receiving team" comment is wrong).
