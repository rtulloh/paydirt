## Description

The owner observed a trailing CPU use its remaining first-half possession
without conserving time. The browser's CPU-call endpoint selects only the
play type, discarding the AI's no-huddle, out-of-bounds, spike, and punt options.
The execute endpoint also discards fourth-down options and never consults the
offensive or defensive strategic timeout policies. CLI routing already retains
these requests. This is a controller integration defect, separate from whether
the coaching policies choose the best tactic in every situation.

## Resolution / verification

Local implementation prepares one server-owned offensive plan for the current
situation and retains it across previews and execution. Changed clock, possession,
down, position, scores, timeout budgets or completed-play history invalidate it.
An explicit different call never inherits unrelated modifiers. Execution passes
the selected options and strategic timeout requests to the engine, which decides
whether a clock-saving procedure is useful and legal.

The same investigation found two silently substituted calls: a CPU Hail Mary
became Line Plunge because its key was absent, and a selected CPU Blitz became
Standard in the preview endpoint. Both mappings now preserve the selected call.
