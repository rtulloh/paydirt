## Description

From the 2026-11-15 Hard playtest (public 1983 Vikings 31, Oilers 20; `python3 -m paydirt -p -H 1983/Vikings -A 1983/Oilers -d hard -c --week 7`). With 3:01 left in Q4 the Oilers trail 20-28 (down 8) and `should_call_timeout_on_offense` returns True (down 8, under 4:00), so the CPU spends its last timeout. The next call is an in-bounds Draw that consumes 38 seconds (3:01 to 2:23) with no no-huddle and no sideline designation. At 2:23, 2:18 and 2:13 the same possession remains in ordinary mode because `_needs_hurry_up` and `_is_two_minute_drill` are both False. No-huddle first appears at 0:27, down 11, when the game is already out of reach. Spending a timeout to preserve clock and then running a 38-second play is worse than doing neither. Separately, the hurry-up gates hardcode a -9 two-score threshold that assumes an 8-point deficit is one possession, which is only true where a two-point conversion exists; 1983 disables it, so down 8 requires two scores (7+3) and should hurry from about 3:00. `_is_two_minute_drill` and `_needs_hurry_up` never read `season_rules.two_point_conversion`, although `get_hurry_up_weights`, AI-029's fourth-down path and the two-point try policy already do. Public synthetic probes at Q4 2:59 down 8 give hurry=False, two_minute_drill=False and no-huddle False under both a no-two-point season and a two-point season, so the era-aware urgency claimed in AI-011 does not reach the pace gate.

## Resolution / verification

The pace gate now counts required scoring possessions from the active season rules. In regulation Q4, a trailing offense that needs at least two scores enters hurry-up strictly below 3:00. An eight-point deficit therefore hurries in a season without two-point conversions, while it remains a one-possession state when two-point conversions are available. Exactly 3:00 remains ordinary, and the new rule does not apply while tied or leading, in earlier quarters, or in overtime.

The implementation candidate applies the same predicate to fourth-down, goal-line, red-zone, analyzed early-down, and ordinary early-down calls, so a qualifying drive requests no-huddle consistently and passing calls can also request the existing sideline designation. Score-count arithmetic used by fourth-down coaching shares the season-rules helper. Synthetic regressions cover both conversion eras, the 2:59/3:00 boundary, earlier-quarter and overtime controls, tied/leading controls, seeded OOB selection, and fourth-down score counting. Keep this ticket open until a play-test or AI audit confirms the late-drive behavior.
