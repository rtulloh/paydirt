## Description

Offense normalizes overtime to quarter 4 (`paydirt/computer_ai.py:138`, `:1110`, `:1165`) but `select_defense` reads `state.quarter` directly (`:871`); overtime sets `quarter = 5` (`game_engine.py:6004`). In modified sudden death, where a defense can lead during an overtime drive, `_opponent_in_hurry_up` and `_should_play_prevent` (`:1083-1097`) never fire. Synthetic reproduction: HOME defense leading by 3 with 3:00 left, 2nd-and-8 at the 40 — in Q4 the defense selects the two-minute package; in overtime with identical facts it selects an early-down formation, and with the quarter normalized it would select the two-minute package. Leading by 14 the prevent check is likewise False only in overtime. `should_onside_kick` (`:842`) ignores overtime similarly. The cause differs from AI-019 (Hard model bypass): this affects all difficulties.

## Resolution / verification

- Normalize overtime in `select_defense` and `should_onside_kick` the same way the offense does; add a Q4-versus-OT parity test for prevent and two-minute defense.
