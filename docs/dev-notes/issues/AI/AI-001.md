## Description

CPU accepts a five-yard automatic-first-down penalty instead of an eleven-yard gain that also earns a first down.

## Resolution / verification

Compare resulting field position and down/distance, rather than automatically preferring an automatic-first-down flag. The latest local audit reconfirmed this choice; use synthetic fixtures for the regression.
