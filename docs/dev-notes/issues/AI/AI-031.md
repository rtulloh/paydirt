## Description

Found in the 2026-11-13 review of the AI-002 fix. The defensive branch of `should_accept_penalty` ranks the retained play against each engine-projected enforcement by remaining distance to the goal, then down, then distance to convert (paydirt/computer_ai.py; the situations come from `_set_defensive_penalty_situations` in paydirt/game_engine.py). Nothing in that ordering considers score, clock or timeouts. Reproduced with public 2026 sample teams: the offense leads 7-0, 35 seconds remain in Q4, it is third-and-10 at midfield after an incompletion, the defense is out of timeouts, and the foul is OFF 5. The CPU enforces the foul, leaving third-and-15 with about 30 seconds, and the offense can kneel out the game; declining leaves fourth-and-10 with the same clock, so the offense cannot run out the clock. The same shape occurs on second down with one defensive timeout left. The AI-002 tests set the clock only in Q1, so this scenario is unrecorded.

## Resolution / verification

- Add failing synthetic regressions with an explicit Q4 clock, score and timeout state for both the trailing-defense and leading-defense situations, before changing the comparison.
- Combine the position/down ordering with the period, remaining time, score differential and timeout counts (or explicitly scope the comparison so a clock-preserving down is not discarded), and record the heuristic and its limits in docs/ai-difficulty.md.
- Confirm in an AI play-test audit that no observed defensive foul choice leaves the offense able to kneel out a game the defense must get the ball back in.

Fixed. `ComputerAI.should_accept_penalty` accepts an optional live engine and
forwards it from the CLI, auto-game, chart-reference audit and all three web CPU
penalty call sites (execute, kickoff and penalty decision). After the existing
position/down comparison picks an enforcement, a trailing Q4 defense evaluates
both choices with the engine's `can_kneel_out_game` rule on shallow copies of the
engine and state. If enforcing the foul permits a kneel-out that declining the
play prevents, the defense declines and returns `None` rather than the stale
enforcement index. Leading defenses, overtime, earlier periods and callers with
no game context retain the AI-002 ordering.

Tests first: the parametrized second-down/one-timeout and third-down/no-timeout
cases failed against the prior implementation by enforcing the foul; the
both-choices-kneel, neither-choice-kneel, leading-defense and no-context controls
passed. A follow-up stale-index regression failed with `(True, 1)` and now
asserts `(True, None)` plus a declined, unchanged down. The backend wiring test
fails with `KeyError: game` when any route drops the context.
