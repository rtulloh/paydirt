## Description

Ordinary-down selection never sets no-huddle even when `_needs_hurry_up` is true (the special-situation branches do).

## Resolution / verification

Apply the shared hurry-up check before standard returns.

Add failing synthetic/public-2026 regressions for ordinary first, second and
third downs when hurry-up is required but the two-minute-drill branch has not
started. Include leading, earlier-game and special-situation controls. Verify
the retained no-huddle option through web/CLI execution and require play-test
confirmation before closure.

Confirmed in a full public 1983 Hard game (Vikings 31, Oilers 20;
`python3 -m paydirt -p -H 1983/Vikings -A 1983/Oilers -d hard -c --week 7`).
Trailing 20-28 with 3:01 left in Q4 and no timeouts, the CPU spent a timeout,
then called an in-bounds Draw that took 38 seconds (3:01 to 2:23) with no
no-huddle and no sideline designation. The next three snaps (2:23, 2:18, 2:13)
also stayed ordinary. No-huddle appeared only at 0:27, down 11.

At that state `_is_two_minute_drill` is False because the 1983 conservative
profile needs a two-score margin of at least nine points inside three minutes
(`score_diff <= -9`), so down eight is treated as one possession. That
assumption only holds where a two-point conversion exists; 1983 disables it.
Public synthetic probes at Q4 2:59 down eight return hurry=False,
two_minute_drill=False and no-huddle False under both no-two-point and
two-point season rules, so ordinary downs never receive the pace option even
when urgency is eventually set.

This is play-test confirmation of the ordinary-down gap, not a fix. The
timeout/pace inconsistency and the season-aware two-score threshold are filed
as AI-035; keep this ticket open until ordinary downs actually carry the
hurry-up and sideline options.
