## Description

In the completed Medium web game, down nine with 18 seconds left, the CPU
chooses Line Plunge on fourth-and-two at its own 28. It gains five yards and
the game expires. Fourth-down selection precedes the two-minute-drill branch
and uses the ordinary short-yardage conversion mixture without assessing the
distance needed for the remaining scores. Matching public-2026 probes choose
78 runs and 22 short passes across 100 seeds. These are selection counts,
not winning probabilities or proof that every run is inappropriate.

## Resolution / verification

Assess time, required scores, scoring distance, timeout availability and clock
effects before choosing a last-possession conversion play. Add failing
synthetic/public-2026 regressions before policy changes. Include the observed
18-second situation, useful short-yardage conversions with sufficient time,
clock-saving options, attainable field goals and existing last-chance pass
controls. Preserve variety where appropriate rather than prescribe a universal
deep-pass rule. Verify the selected plan through real-engine execution and
require issue-specific play-test confirmation before closure.
